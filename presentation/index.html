Limits / Research presentation

What limits these results

01 / Sample

Convenience sample

The convenience sample included 97 students, 17 of whom met the High cutoff.

02 / Timing

Current symptoms

We measured current symptoms once, so future burnout and causal direction remain unknown.

03 / Selection

Repeated use of the same sample

Earlier model choices used this same sample, which can make performance estimates optimistic.

04 / Generalization

No independent cohort

We still need measured burnout scores from an independent group.

For a future test, we would set the procedure before testing it on new students. This phase has no further recruitment.

A6 · Permutation test and paired bootstrap

Permutation / 199 runs

Rerun the procedure with shuffled labels

Shuffle one label per student while keeping 17 High and 80 Below-high labels. Rebuild the folds, then tune and fit the forest.

p = (b + 1) / 200 = 0.005
No shuffled run reached the observed value.

Bootstrap / 2,000 samples

Resample students with their existing predictions

Sample students within their outcome group, with replacement. Keep all five predictions per student and pair the resamples across models.

Use the middle 95% of the resampled estimates.

The permutation test repeats only the selected procedure. The bootstrap keeps predictions fixed, so its intervals exclude variation from retraining and model selection.
